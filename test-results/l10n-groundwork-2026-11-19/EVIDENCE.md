## Part 2: what inject does with a segment `02-structure` does not list

The plan's §5.3 asked for this before any insertion overlay is designed.

**Method.** `probe-unlisted-segment.mjs` (beside this note) calls the exported `buildCnxml` from
`tools/cnxml-inject.js` in memory, with the real `02-structure`, `02-mt-output`, `02-for-mt` and `01-source`
files, read-only. It runs three arms per module:
- A: the module as it is;
- B: A plus three segments whose ids `02-structure` does not list (`:para:loc-new-001`, `:note:loc-box-001`,
  `:exercise:loc-ex-001`), each holding a unique sentinel;
- C: a positive control that replaces one existing para's text with a sentinel.

Math-label substitution was skipped, which is the same in every arm. Run on `main` at `474647ffb` plus one
register-only commit.

**Result** (`probe-result.json`, `probe-result-m68683.json`):

| Module | Segments in file | A resolved | B output identical to A | B complete | B sentinels in output | B stderr | C sentinel |
|---|---|---|---|---|---|---|---|
| m68667 (1.2) | 214 | 201 | **yes** (47,583 bytes) | true | 0 / 0 / 0 | nothing | 1 |
| m68683 (1.6) | 232 | 229 | **yes** (58,595 bytes) | true | 0 / 0 / 0 | nothing | 1 |

**What it means.**
- Inject is driven by the structure. It walks `02-structure` and asks for each id, so a segment the structure does
  not list is never read. **Its text is dropped silently**: the module is still "complete", and nothing is printed
  without `--verbose`.
- With `--verbose`, the only trace is `"N segments in translation file not referenced by structure"`. That line
  cannot tell an inserted segment from the ones already unreferenced in today's files: 13 in m68667, 3 in m68683.
- So an insertion needs the overlay the plan proposes, read by inject on the localized track. Adding segments to a
  segment file reaches no reader and raises no alarm. That is the dangerous case, since a localizer would see their
  text saved in the editor and missing from the page.
- When the overlay is built, its test should use this probe's shape: a sentinel per inserted element, compared by
  value at the element keyed by its new id (CLAUDE.md, "prove a translation reached the output with a sentinel"),
  with arm C as the positive control.
