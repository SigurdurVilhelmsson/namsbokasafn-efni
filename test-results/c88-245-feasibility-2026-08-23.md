## The existing precedent — this is an extension, not an invention

`collectFigureAlts` (`tools/cnxml-inject.js:1799-1812`) and `applyFigureAltDom` (`:2547-2573`)
**already solve the id-less-media problem for figures**: the map keys on the **figure** id and
carries `mediaId: null`, which `applyFigureAltDom` resolves as *"the figure's first media."*
Its own comment records why — *"243 of organic's 1,918 alt translations are on ID-LESS media,
and requiring an id skipped every one."* **The same book, the same cause, already handled once.**

## The work, as two units

### Unit A — the 244 in Branch 3 · **small: one focused session, one PR**
1. `tools/cnxml-extract.js:1557` — relax `if (!media.id) continue` to carry a key instead of skipping.
2. 🔴 **The seg-id is the one real design decision.** That site calls `altElementId(media.id, 0)`
   with a **hardcoded index 0**, so id-less media in a module would all collide on
   `media-0-alt`. **The guard was suppressing two failures while documenting one** — an
   unresolvable inject key *and* a seg-id collision. A deletion is not enough; a key is required.
3. `tools/cnxml-inject.js` — `buildTable` already holds `cell` at its
   `applyMediaAltString(entryMatch, ctx)` call (`:2896`, inside the `rowIdx`/`cellIdx` loop), so
   the cell's alt can be passed **directly**; `collectMediaAlts`' id-keyed table branch (`:1864`)
   need not change. Teach `applyMediaAltString` the no-`mediaId` case.

### Unit B — the 1 in Branch 1 (`m00032`) · **price separately; do not fold in**
That cell holds one `<media>` and one `<para>` — **the exact cell §C85 just fixed**, pinned by
`tools/__tests__/table-entry-media-preserved.test.js`. Wiring an emitter into the `cell.paras`
branch means touching code whose **sibling branch destroys non-para content**, in the module that
most recently had a defect there, against a fresh pin. **A different risk class from relaxing a
guard in Branch 3.**
📌 **Independently corroborated:** `cnxml-extract.js:1509` records *"entries holding exactly one
`<para>` are 2 in lifraen-efnafraedi … and exactly ONE of those also holds a `<media>`."* This
probe finds exactly 1. Two tasks, different methods, same answer.

## Which key — and the default is not the obvious one

**`src` is the stronger candidate.** Content-anchored, survives re-extraction unchanged,
independent of both cell indexing and "first media" ordering, and measured **unique for all 245
within their module**. Position is *available* (0/822 disagreement today) but inherits any future
indexing drift — and 🔴 **an alt written to the wrong cell is silent: no count moves.** That is
the §C89 failure shape this whole thread exists to prevent.
⚠️ **Do not copy `applyFigureAltDom`'s "first media" for the reason it chose it** — a figure has
one media by construction; a table cell does not. The 0-multiplicity measurement makes "first"
*safe here today*, which is not the same as *principled*.

## Pins that move — the hidden cost

- `tools/__tests__/alt-writeback-corpus.test.js` — organic **1918 → 2162** (+244).
- `tools/__tests__/cnxml-extract-alt-corpus.test.js` — organic counts.
- 🔴 `tools/__tests__/inject-roundtrip-corpus.test.js` — **real work, not a footnote.** Per
  [`c85-c90-root-cause-synthesis-2026-08-23.md`](c85-c90-root-cause-synthesis-2026-08-23.md), its
  third assertion `expect([...loss, ...gain].every((x) => x.ok === false)).toBe(true)` **passes
  vacuously on empty arrays**. Whoever moves that pin must **re-point it at something**, or the
  suite silently loses its only `ok === false` assertion on a real corpus defect.
- `tools/__tests__/alt-coverage-corpus.test.js` pins **chemistry only** — does **not** move.

⚠️ **Acceptance must be a SENTINEL SUBSTITUTION, never a count** (§C89's durable rule): overwrite
each of the 244 with a token that cannot have come from source, inject, count tokens — **with the
1,918 that already work asserted alongside as a built-in positive control**, so a harness that
breaks everything equally cannot read as a pass.

## The expensive variable is the window, not the code

These 244 are **extraction-side**. Taken **before** runbook Phase 3 they ride the clean-break
re-extract for free; taken **after**, they need a second re-extract and a second re-key of
organic's seg-ids — the join key for TM and the export corpus. **This is the same scheduling
logic the register applied to §C85/§C90.** Marginal MT is 244 short alt strings against a
342-module book, and is exactly measurable by the `--dry-run` runbook Phase 1.3 already calls for.
