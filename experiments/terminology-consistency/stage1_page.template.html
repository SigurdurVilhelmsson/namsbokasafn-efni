Chemistry term rulings: stage 1

Close the ruling set before the machine-revised layer is built. Every answer saves to this page as you go, so short sittings work. Where a default is shown, change it only if you disagree, then press Confirm this list at the end of the tab, so a list you have not reached yet stays open.

How the answers are used

  • Scope is the whole book by default (your D2). A card has a scope control for a ruling that should hold only in some chapters, or everywhere except some.
  • “July word” is the key-terms entry readers see on the live site now. “September word” is the new MT's entry, which is the base text (your D1).
  • Answers are compiled into one dated ruling-set file in the repository, together with the rulings already in force. Nothing reaches the text, the glossary or the editors from this page directly.
  • The counts measure consistency, not correctness. A word used everywhere can still be wrong, so the word is yours to choose.
