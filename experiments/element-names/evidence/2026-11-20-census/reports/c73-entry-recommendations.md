# Draft §C73 recommendations: book glossary entries for the 68 element names with no chemistry row

**A draft for [USER]'s ruling, not a ruling.** Built by `instruments/build-c73-recommendations.py` from the measurement-4 census and the official list (Vísindavefur 89909). §C73 (CLAUDE.md) asks what the MT does unprompted; the rule below makes that test explicit.

## The rule

1. **Absent from the book:** no entry. Nothing to check.
2. **Homograph:** no entry. *lead* is also the English verb "lead" (as in "lead to"); an entry would make the editor's term check fire on it (CLAUDE.md, wrong-sense homographs).
3. **Never official:** entry. The MT never produces the official name.
4. **Unreliable:** entry, when 10% or more of the MT's forms are not official.
5. **Reliable:** not needed by §C73, when under 10% are not official. The drafted fixes clear those; an entry would only add protection against future regressions, which is a separate choice.

**10% is the one free parameter.** Every name's share is in the table, so moving it moves only rows 4–5. Occurrences count standalone forms and compounds, in segments whose English names the element (measurement 4). Noise bases (`kalkstein`, `aktiníðaröðin`, `alúmín`) are left out. Beryllium's one-*l* forms and hafnium's `hafnfn` garble are counted as non-official.

## Not measured

- **How the editor's term check treats compounds.** An entry makes the term check expect the official name wherever the English names the element. For the frequent names (magnesium 119 segments, helium 55) a segment that uses the official name only inside a compound could draw a warning, if the check does not see compounds. Enter one such entry first and read its warnings before entering the rest.


## Not in the 68, but related

- **aluminum** (US spelling; OpenStax uses it): chemistry resolves only the British *aluminium* (`ál`), so the editor's term check never fires on *aluminum*. The MT writes `ál` consistently (183 occurrences). §C73 does not ask for an entry; adding *aluminum* as an English form of `ál` would only make the term check see it.
- **How an entry here behaves:** none of these names has a chemistry row to replace, so each entry is an *add*. The page gives an add no worklist (`add-alongside`), so the segment fixes come from measurements 8–9, not from the page.
