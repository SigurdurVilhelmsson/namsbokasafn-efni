# Documentation

This directory contains the documentation for the Námsbókasafn translation project.

**Where a fact lives is set by the *One source of truth* section of [CLAUDE.md](../CLAUDE.md).**
In short: open work (what is next, blocked, shipped) lives only in the active register;
durable rules live in `CLAUDE.md`; decisions that no single item owns live in
[decisions/](decisions/); and dated, frozen documents are evidence, cited as written and never
updated to match the present. Many documents below are dated. Where one disagrees with the
register or with the code, the register and the code win.
